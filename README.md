# Portfolio de José Burguillos

Portfolio personal de desarrollo web, soporte IT y automatización con IA. Diseño editorial sobrio: tipografía serif para los titulares, azul cobalto como único acento y animaciones sutiles que acompañan el scroll.

## Contenido

- Presentación personal con roles rotativos, retrato y cifras clave.
- Sobre mí, datos rápidos y selector entre perfil de desarrollo y de soporte IT.
- Experiencia en Deuser / Indra Group y Recosur con línea temporal animada.
- Proyectos: asistente inteligente para reformas (n8n + IA), ADOPT-ME y sistema de fichaje.
- Competencias, formación, idiomas y contacto con descarga del CV en español e inglés.
- Diseño responsive, navegación accesible y soporte para movimiento reducido.

## Estructura

- `index.html`: contenido y estructura semántica.
- `portfolio.css`: sistema visual, animaciones y responsive.
- `portfolio.js`: navegación, pestañas, contadores, revelado al hacer scroll y efectos de puntero.

No requiere instalación ni proceso de build; basta con servir la carpeta mediante un servidor estático.
