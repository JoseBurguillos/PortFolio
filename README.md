## Tecnologías del sitio

El portfolio está construido como una página estática con HTML5 y CSS3, sin dependencias de ejecución. Incluye diseño adaptable, navegación accesible, metadatos SEO y enlaces directos a los proyectos publicados.

## Vista local

Puedes abrir `index.html` directamente en el navegador o servir la carpeta con cualquier servidor HTTP local.

```bash
python -m http.server 8000
```

Después, abre `http://localhost:8000`.

## Despliegue
