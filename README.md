# Portfolio de José Burguillos

Portfolio profesional alineado con mi CV y orientado a oportunidades de **desarrollo web junior**, **soporte IT** y **automatización con IA**.

🌐 **Web:** [joseburguillos.vercel.app](https://joseburguillos.vercel.app)<br>
👤 **GitHub:** [JoseBurguillos](https://github.com/JoseBurguillos)<br>
💼 **LinkedIn:** [José Burguillos](https://www.linkedin.com/in/jos%C3%A9-burguillos-88834932a/)

## Contenido

- Presentación personal con roles rotativos, retrato y cifras clave.
- Sobre mí, datos rápidos y selector entre perfil de desarrollo y de soporte IT.
- Experiencia en Deuser / Indra Group y Recosur con línea temporal animada.
- Proyectos: asistente inteligente para empresas de reformas (n8n + IA), ADOPT-ME y sistema de fichaje.
- Competencias, formación, idiomas y contacto con descarga del CV en español e inglés.

## Diseño

Estilo editorial sobrio: tipografía serif para los titulares, azul cobalto como único acento y animaciones sutiles que acompañan el scroll. Diseño adaptable, navegación accesible y soporte para movimiento reducido.

## Estructura

- `index.html`: contenido y estructura semántica.
- `portfolio.css`: sistema visual, animaciones y responsive.
- `portfolio.js`: navegación, pestañas, contadores, revelado al hacer scroll y efectos de puntero.

## Vista local

Puedes abrir `index.html` directamente en el navegador o servir la carpeta con cualquier servidor HTTP local.

```bash
python -m http.server 8000
```

Después, abre `http://localhost:8000`.

## Despliegue

La rama `main` se publica en Vercel. El CV descargable se mantiene en `CV_Jose_Burguillos_ATS.pdf` para conservar estable el enlace público; la versión en inglés está en `CV_Jose_Burguillos_English.pdf`.
